================================================================================
                    UDDHARSETU SYSTEM REVIEW & ARCHITECTURE
================================================================================

1. DIRECTORY STRUCTURE
-----------------------
- client/: Public portal (React + Vite)
  - src/App.tsx: Main dashboard routing, session loader, and Khalti lookup checker
  - src/components/: Shared layout (Topbar, AuthPanel, RequestList, forms)
  - src/pages/: Context pages (HomePage, CampaignsPage, WorkerPage, AdminPage, KycPage)
- server/: Core API services (Node.js + Express + pg)
  - src/index.ts: Route registration and server listener
  - src/auth.ts: Session handlers, Google authentication middleware
  - src/db.ts: Raw PG database setup, DDL schema declarations
  - src/kyc.ts: KYC submission routing, admin reviews
  - src/posts.ts: Campaigns and help requests query managers
  - src/donations.ts: Khalti payment integration, material pledges, and drop-off verification

2. CURRENT DATABASE RELATIONS
-----------------------------
- users: Google OAuth mapped profiles (id, email, role, status ['PENDING', 'APPROVED', 'REJECTED'])
- user_sessions: Active developer/Google session hashes with expiration tracking
- relief_posts: Social worker campaigns (post_type ['HELP', 'FUNDRAISING'], target_quantity, target_amount, fulfilled_quantity, fulfilled_amount, review_status)
- kyc_submissions: Documents and photographs verifying social worker identity (with admin notes)
- relief_pledges: Donor commitments (pledge_type ['FINANCIAL', 'MATERIAL'], quantity, amount, secure_token, status)

3. KEY INTEGRATED WORKFLOWS
---------------------------
- Google Authentication / Mock Local Auth (testing bypass)
- Verification pipeline (KYC upload -> admin review with notes -> worker status updates)
- Campaign flow (Worker form separated into Material Help Request and Financial Fundraiser)
- Anonymous donor fulfillment:
  - Khalti Payment Integration: initiates payment securely, redirects client, looks up transaction completion, updates campaign balance within isolated row locks
  - Material pledges: reserves quantities using concurrency-safe capacity checking, issues drop-off tokens
- Token-authenticated drop-off hubs: Social worker console scans drop-off token, completes material pledge, and updates relief posts ledger.
